
# **📚 Переработка учебно-методических материалов**

Проект по адаптации и модернизации учебных материалов для изучения Data Science с использованием современных версий библиотек и инструментов.

## **🎯 Цель проекта**
Преобразование сложной книги по ИИ в доступный учебный материал для студентов с использованием современных Data Science инструментов.

## **📁 Структура проекта**

```
DataSciencePractice/
├── README.md                    # Описание проекта
├── .gitignore                   # Игнорируемые файлы
├── requirements.txt             # Зависимости Python
├── startup.sh                   # Установка для Linux/Mac
├── startup.ps1                  # Установка для Windows PowerShell
├── manual.md                    # Инструкция для виртуальной среды
├── chapters/             
```

## **🚀 Быстрый старт**

### **1. Клонирование и настройка**
```bash
git clone https://github.com/Oxsine/DataSciencePractice
cd DataSciencePractice
```

### **2. Установка окружения**
```bash
# Windows
./starup.ps1

# Дистрибутивы Linux/Mac
bash startup.sh
>>>>>>> develop
```

### **3. Активация окружения**
```bash
# Windows (PowerShell/CMD)
venv_ds\Scripts\activate.bat

# Linux/Mac
source venv_ds/bin/activate
```

### **4. Запуск Jupyter**
```bash
jupyter notebook
```
Выберите ядро: **"Python (Data Science)"**
